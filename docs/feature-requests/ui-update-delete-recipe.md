## FEATURE:

Add screen to update an existing recipe.
On the recipe detail screen add an "Edit" button as FAB that navigates to the update screen.
For the update screen, use the same form as for creating a recipe, but pre-fill it with the existing recipe data.
Use the existing widget but rename it to `recipe_form_widget.dart`.
Path to this screen should be `/recipes/:id/edit`.
After edit user should be redirected to the recipe detail screen with updated data.
Additionally, add a "Delete" button to the recipe detail screen that allows users to delete the recipe.
"Delete" button should be a red icon button in the app bar.
