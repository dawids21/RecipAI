# Execute SIP

Implement a feature using the SIP file. You can always reference the SIP again if needed.

## SIP File: $ARGUMENTS

## Execution Process

1. **Load SIP**
   - Read the specified SIP file
   - Understand all context and requirements
   - Follow all instructions in the SIP and extend the research if needed
   - Ensure you have all needed context to implement the SIP fully
   - Do more web searches and codebase exploration as needed

2. **ULTRATHINK**
   - Think hard before you execute the plan. Create a comprehensive plan addressing all requirements.
   - Break down complex tasks into smaller, manageable steps using your todos tools.
   - Use the TodoWrite tool to create and track your implementation plan.
   - Identify implementation patterns from existing code to follow.

3. **Execute the plan**
   - Execute the SIP
   - Implement all the code

4. **Validate**
   - Run each validation command
   - Fix any failures
   - Re-run until all pass

5. **Documentation**
   - Check what was changed during the implementation
   - Update the documentation

6. **Complete**
   - Ensure all checklist items done
   - Run final validation suite
   - Report completion status
   - Read the SIP again to ensure you have implemented everything

7. **Report**
   - Create new file in `docs/reports/` with the name `{date}-{feature_name}.md`
   - Report the completion status of the SIP
   - Add any task that come up during the implementation that is not part of the SIP
   - If any issues arise, report them and suggest next steps
